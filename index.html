Data & settings

Your workout data is stored in this browser on this device. It is not sent to a server by this file. Export a backup regularly.

Important: clearing Safari website data, using a different browser, or opening the HTML in a different app may make existing logs unavailable. Export a backup before changing phones or clearing data.

How to use on iPhone

  1. Save this HTML file to the Files app.
  2. For reliable Home Screen use, open the file from a local/offline HTML viewer that uses the same persistent browser storage, or host the same file on a private static website and open it in Safari.
  3. In Safari, tap Share → Add to Home Screen when available.
  4. Open the tracker from that same Home Screen icon each time; browser storage can differ between apps and contexts.
  5. Use Export backup after each week. Keep the JSON file in Files or iCloud Drive.

This is a single-file offline tracker, not a cloud-syncing app. iOS may restrict Add to Home Screen for file:// pages; if so, use a static HTTPS host to install it as a Home Screen web app. The app itself makes no network requests.
